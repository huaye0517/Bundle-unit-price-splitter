# 组合装单价拆分工具

Windows 原生桌面工具：已内置《组合装及子件合并数据》基础库，拖入销售单即可一键生成带服务费、手续费、赔偿、需拆金额和订单核对汇总表的结果工作簿。计算引擎和基础库均内嵌在单个 EXE 中。

## 基础数据与拖拽

- 首次运行会从 EXE 初始化本地基础库，后续更新会保留在当前电脑。
- “新增”按“母件编号 + 子件编号”去重追加，不覆盖已存在的组合；“覆盖”用所选工作簿整体替换当前基础库。
- 基础数据和销售单区域都支持直接拖入单个 `.xlsx` 文件，也保留文件选择按钮。
- 订单存在服务费或赔偿时，勾选“包含服务费/赔偿账单”后选择或拖入引用表；不勾选时该区域隐藏，服务费和赔偿按 0 处理。

## 计算规则

- AE：使用销售表货品编号，在旧版占比表 `Sheet2` 中匹配“单品编号/单价”，或在新版导出表（如 `sheet1`、`总表`）中匹配“编号/执行价格”；合并文件中重复出现的表头会自动跳过，未匹配填 0。
- 原“金额”为 0 的行不参与占比和金额分摊，AE、AH、AL 均填 0。
- 优先使用销售表中的“网店订单号 + 订单金额”；没有“订单金额”列时，使用销售明细中的“网店订单号 + 应收合计”。采用独立订单金额时，结果页 N 列会同步为该金额。
- 同一网店订单的“应收合计”即使在多行重复显示，也只作为整单总额使用一次，不会逐行累加或重复扣费。
- 引用账单按“订单号”汇总“服务费”和“补偿/赔偿”，结果页 O、Q 写入汇总数值；同一销售订单多行重复显示但只扣减一次。
- P：`N × 1%` 手续费；R：`N - O - P - Q`，R 是整单实际拆分基数。
- AF：`AE / 网店订单内 AE 合计 / 数量`；AG：订单需拆金额 × AF；AH：`AG × 数量`。
- AL：与 AH 逐行一致。
- 自动生成“透视表”核对页，B 列显示每单唯一 R“需拆金额”，C 列汇总 AH，D 列为 `B-C`。
- 整个网店订单都未匹配占比表时，按各行原金额占比分摊 Sheet1 订单金额；原金额为 0 的行仍不参与。
- 拆分列写入数值且不额外舍入；P、R 保留可核对的工作表公式。
- “订单金额”和“应收合计”的外部公式会使用源文件中的已计算结果固化为数值，避免保存后显示为空；没有缓存值时会提示先用 Excel/WPS 打开并保存源文件。
- 引用表缺少“订单号、服务费、补偿/赔偿”会停止生成；服务费或赔偿公式没有缓存值时也会给出明确提示。

## 运行源码

```powershell
python splitter_worker.py 占比表.xlsx 销售单.xlsx 输出.xlsx
python splitter_worker.py 占比表.xlsx 销售单.xlsx 输出.xlsx 服务费赔偿引用表.xlsx
```

## 测试与打包

```powershell
.\build.ps1
```

打包完成后，程序位于 `outputs\组合装单价拆分工具.exe`，可直接复制到其他 Windows 电脑运行。

如需指定打包使用的 Python，可先设置 `BUNDLE_SPLITTER_PYTHON` 环境变量。真实样例回归测试可通过 `BUNDLE_SPLITTER_RATIO_SAMPLE` 和 `BUNDLE_SPLITTER_SALES_SAMPLE` 指定本机文件，不会把业务表上传到仓库。
