# 组合装单价拆分工具

Windows 原生桌面工具：已内置《组合装及子件合并数据》基础库，拖入销售单即可一键生成带拆分金额、手续费、最终金额和订单核对汇总表的结果工作簿。计算引擎和基础库均内嵌在单个 EXE 中。

## 基础数据与拖拽

- 首次运行会从 EXE 初始化本地基础库，后续更新会保留在当前电脑。
- “新增”按“母件编号 + 子件编号”去重追加，不覆盖已存在的组合；“覆盖”用所选工作簿整体替换当前基础库。
- 基础数据和销售单区域都支持直接拖入单个 `.xlsx` 文件，也保留文件选择按钮。

## 计算规则

- 新版基础库按销售表 AL 备注中的“编号”匹配“母件编号”，再用 V“货品编号”匹配该母件下的子件编号；AA 写入对应执行价格，组内使用基础表“分摊比例”。
- 同一 K“网店订单号”内按 B“订单编号”分别拆分；每个 B 使用自己的唯一 N“应收合计”，并扣除该 B 的 `AG 金额合计 × 1%` 手续费。
- 一个 B 含多个母件或普通商品时，先按各组原 AG 金额分配净额，再在母件组内按当前出现子件的分摊比例归一化拆分。
- AL 为空或母件与子件无法联合匹配时，相关行按 `Z 单价 × Y 数量` 比例兜底；Z 或原金额为 0 的免费子件不参与拆分。
- 旧版占比表 `Sheet2` 继续按“单品编号/单价”执行原有拆分逻辑。
- AB：每单位占当前 B 订单拆分总额的比例。
- AC：当前 B 订单拆分总额 × AB。
- AD：`AC × 数量`。
- AH：`AG × 1%` 手续费。
- AI：`N - AH` 最终金额。
- AJ：与 AD 逐行一致。
- 自动生成“透视表”核对页，B 列汇总同一 K 下各 B 的扣费后目标金额，C 列汇总 AD，并计算差异。
- 拆分列写入数值且不额外舍入；AH、AI 保留可核对的工作表公式。
- “订单金额”和“应收合计”的外部公式会使用源文件中的已计算结果固化为数值，避免保存后显示为空；没有缓存值时会提示先用 Excel/WPS 打开并保存源文件。

## 运行源码

```powershell
python splitter_worker.py 占比表.xlsx 销售单.xlsx 输出.xlsx
```

## 测试与打包

```powershell
.\build.ps1
```

打包完成后，程序位于 `outputs\组合装单价拆分工具.exe`，可直接复制到其他 Windows 电脑运行。

如需指定打包使用的 Python，可先设置 `BUNDLE_SPLITTER_PYTHON` 环境变量。真实样例回归测试可通过 `BUNDLE_SPLITTER_RATIO_SAMPLE` 和 `BUNDLE_SPLITTER_SALES_SAMPLE` 指定本机文件，不会把业务表上传到仓库。
